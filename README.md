# Rinintha Pradiza — Portfolio

Portfolio website for Rinintha Pradiza, built with Next.js and ready for Vercel.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm start
```

Every push to the connected GitHub repository can be deployed automatically by Vercel.

## Website statistics

- Production site: https://www.rinintha.com (Vercel project `rinintha`).
- Visitor counts, page views, referrers and devices: https://vercel.com/rinintha1/rinintha/analytics
- Google Analytics: https://analytics.google.com — account **Rinintha Pradiza**, property **rinintha.com**, stream **rinintha.com website**, measurement ID **G-Y2701E2FV6**.
- In Google Analytics, use **Reports → Engagement → Pages and screens** (or **Business objectives → View user engagement & retention → Pages and screens**) for page views and average engagement time. Realtime shows recent visits; standard reports may take 24–48 hours.
- Vercel Analytics was enabled on September 25, 2026. Earlier visits cannot be reconstructed from it.
- Google Analytics loads only after a visitor accepts analytics cookies. The English/Japanese preference panel explains data use; visitors can reopen it at the bottom of any page. Preferences expire after 180 days. Declining disables the tag and removes its first-party cookies. Google advertising consent and personalization stay disabled.
- Google engagement time measures active viewing, not simply how long a tab remains open. Reports cover consenting visitors and may exclude visits blocked by browsers or extensions.
